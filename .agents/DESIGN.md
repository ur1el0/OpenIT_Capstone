# Paldo Design Specifications

## 1. UI/UX Principles
- **Modern & Premium Feel:** The interface must use modern aesthetics (glassmorphism where appropriate, vibrant and distinct colors, smooth gradients).
- **Responsive Layout:** The application must look excellent and be fully functional on mobile, tablet, and desktop viewports.
- **Micro-Animations:** Use subtle hover states and transitions to provide dynamic feedback to user interactions.

## 2. Accessibility (a11y)
- **Semantic HTML:** Strict usage of semantic tags (e.g., `<nav>`, `<main>`, `<article>`).
- **ARIA:** Proper ARIA labels for dynamic content and custom interactive elements.
- **Keyboard Navigation:** Full support for navigating the application via keyboard.
- **Contrast:** Ensure all text and interactive elements meet WCAG contrast requirements.

## 3. Design System (Frontend)
- **Framework:** React with Vite.
- **Styling:** Vanilla CSS (or preferred pre-processor) using a predefined set of design tokens (colors, typography, spacing).
- **Typography:** Modern fonts (e.g., Inter or Roboto).
- **Icons:** Standardized icon set for consistent visual language.
