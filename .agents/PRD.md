# Paldo Product Requirements Document (PRD)

## 1. Project Overview
**Name:** Paldo (Barangay Scholarship System)
**Purpose:** A full-stack scholarship application system connecting students with local government (Barangay) scholarship providers.

## 2. Target Audience
- **Students / Applicants:** Need a platform to easily apply for scholarships, track status, and view announcements.
- **Barangay Officials / Administrators:** Need a dashboard to review applications, approve/reject them, and manage scholarship programs.

## 3. Key Features
- **Student Dashboard:** Track application lifecycle (pending, approved, rejected, completed).
- **Admin Dashboard:** Review and process applications.
- **Authentication & Authorization:** Secure login with distinct roles (Student vs. Admin).
- **Responsive UI:** Accessible and modern UI using React.
- **Robust Backend:** Secure data processing using ASP.NET Core.

## 4. Non-Functional Requirements
- **Security:** Granular RBAC, secure DTO mapping, and endpoint protection.
- **Performance:** Optimized database queries, caching where appropriate.
- **Accessibility (a11y):** Keyboard navigation and ARIA compliant frontend.
